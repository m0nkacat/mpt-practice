## Предметная область
Платформа, где пользователи могут задавать вопросы, отвечать, комментировать и добавлять теги.

## Папки
bin - точка входа
lib/src/domain - модели данных и валидаторы (не зависят от БД и CLI)
lib/src/data - работа с SQLite (таблицы, CRUD-репозитории)
lib/src/cli - меню и вспомогательный ввод с валидацией
test - тесты для каждого слоя

## Слои
domain - классы, методы, валидаторы
data - БД, создание таблиц, репозиторий 
cli - цикл меню, запрос ввода с повторными попытками, вызов репозиториев

## Валидация
Обязательное текстовое поле - проверка, что строка не пуста
Положительное число - ID, количество, рейтинг и т.д.

## Тесты
domain_test.dart - проверка сериализации моделей
data_test.dart - тесты репозиториев на временной БД
validation_test.dart - проверка валидаторов
